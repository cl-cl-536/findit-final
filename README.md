# FindIt Final

## Getting Started

### 1. Clone the Repository

Open the terminal and run:

```bash
git clone https://github.com/YOUR-USERNAME/findit-final.git
```

Navigate to the project folder:

```bash
cd findit-final
```

### 2. Open in VS Code

```bash
code .
```

### 3. Get Latest Changes

Before starting work, run:

```bash
git pull origin main
```

### 4. Upload Your Changes

After completing your work, run:

```bash
git add .
git commit -m "Describe your changes"
git push origin main
```

**Note:** Pull the latest changes before working to avoid conflicts. Never upload your `.env` file or API keys.
